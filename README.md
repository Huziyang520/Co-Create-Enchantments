# Co-Create Enchantments

**English** | [简体中文](#简体中文)

## English

**Co-Create Enchantments** is an enchantment mod built together by players, developers, and the community. Every enchantment is a self-contained mechanic instead of a flat stat boost.

### A few examples

| Enchantment | Applies to | What it does |
|---|---|---|
| **Gentle Descent** | Boots | Keeps Slow Falling active while worn; sneaking cancels it until you stop sneaking. |
| **Undying Drop** | Chestplates | On a lethal hit, drops everything you carry and wear, consumes the enchantment, and leaves you alive on one heart with Regeneration, Absorption, Fire Resistance, and Darkness. |
| **Chinese** | Chestplates | Grants creative flight while worn, and takes it away again when removed. |

### Obtaining

These enchantments never appear at the enchanting table. Apply them from enchanted books, or with `/enchant`.

### Configuration

Each enchantment has tunable numbers such as durations and Darkness. Edit the generated server config, or open the in-game config screen — from Mod Menu on Fabric, and from the Mods list on NeoForge.

### Requirements

- [MerlinLib](https://github.com/Huziyang520/MerlinLib), on both the client and the server.
- Fabric builds also need Fabric API and Forge Config API Port; NeoForge builds need nothing beyond NeoForge itself.

### Feedback

Ideas and bug reports are welcome in the [issue tracker](https://github.com/Huziyang520/Co-Create-Enchantments/issues).

## 简体中文

**共创附魔（Co-Create Enchantments）** 是由玩家、开发者与社区共同打造的附魔模组。每个附魔都是一套独立机制，而不是单纯的数值堆叠。

### 部分附魔示例

| 附魔 | 适用物品 | 效果 |
|---|---|---|
| **羽落** | 靴子 | 佩戴期间持续获得缓降；潜行时取消，停止潜行后恢复。 |
| **掉落不死亡** | 胸甲 | 受到致命伤害时，背包与身上的物品全部掉出、附魔自身消耗，你以一颗心存活，并获得生命恢复、伤害吸收、抗火与黑暗。 |
| **中国人** | 胸甲 | 佩戴期间获得创造飞行，取下后立即失去。 |

### 获取方式

这些附魔不会出现在附魔台上。可以用附魔书在铁砧上添加，或使用 `/enchant`。

### 配置

每个附魔都有可调数值，例如持续时间与黑暗时长。可以编辑生成的服务端配置文件，也可以在游戏内打开配置界面——Fabric 从 Mod Menu 进入，NeoForge 从模组列表进入。

### 前置

- [MerlinLib](https://github.com/Huziyang520/MerlinLib)，客户端与服务端都需要安装。
- Fabric 端还需要 Fabric API 与 Forge Config API Port；NeoForge 端除 NeoForge 本身外无需其它前置。

### 反馈

欢迎在[问题追踪](https://github.com/Huziyang520/Co-Create-Enchantments/issues)提出创意或报告问题。
